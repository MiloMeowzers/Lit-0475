# The Importance of Being Earnest – IGCSE 0475 revision guide

Private revision resources for Cambridge IGCSE Literature in English 0475 (Paper 2 Drama, exams 2028–2030).

- `Importance_of_Being_Earnest_Revision_Guide.pdf` – the printable guide (42 pages).
- `index.html` – the same guide as a single web page, with the event bank, quote bank and theme arcs filterable by act and theme. Open it directly or publish it with GitHub Pages.

References take the form I.202 (Act I, speech 202), counted in the Project Gutenberg text of the play (eBook #844). Every quotation and reference was checked against that text.
