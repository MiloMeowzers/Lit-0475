# The Importance of Being Earnest – IGCSE 0475 revision guide

Revision resources for Cambridge IGCSE Literature in English 0475 (Paper 2 Drama, exams 2028–2030).

- `Importance_of_Being_Earnest_Revision_Guide.pdf` – the printable guide (42 pages).
- `index.html` – the guide as a single web page, with an event bank, quote bank and theme arcs filterable by act and theme. 

References take the form I.202 (Act I, line 202), counted in the Project Gutenberg text of the play (eBook #844).
